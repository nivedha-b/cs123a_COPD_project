# cs123a_COPD_project
This project focuses on conducting a genomic analysis of the susceptibility of individuals to COPD.  It is designed as a focused, in-silico study to identify genetic drivers of Chronic Obstructive Pulmonary Disease (COPD) by re-analyzing existing, publicly available large-scale genomic datasets.

## Current Progress 5/3/2026
- Completion of data loading and preprocessing 
- Implementation of association testing 
- Pending visualization and pathway analysis
